# Secure-Notes-Vault

A full-stack web application that allows users to securely create, store, and view encrypted personal notes. Built using Python, C, SQL, and Flask, this project demonstrates systems-level programming, backend development, and web integration.

---

## Features

- ✍️ Create and save personal notes
- 🔒 Notes are encrypted using a C module before storage
- 🗃️ Encrypted notes are stored in a local SQLite database
- 🔓 Notes are decrypted on-demand for viewing
- 🌐 Simple and responsive web interface

---

## 🧰 Tech Stack

| Layer         | Technology Used                     |
|---------------|-------------------------------------|
| Front End     | HTML, CSS, JavaScript               |
| Back End      | Flask (Python)                      |
| System Module | C (compiled as shared library)      |
| Database      | SQLite                              |
